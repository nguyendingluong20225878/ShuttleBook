# F09.3 — quan sát vận hành local

Ngày 2026-10-09. Trạng thái: **snapshot/runbook đang triển khai; diễn tập lỗi/Worker chưa chạy**.

## Phạm vi và contract

- Script read-only kiểm HTTP `/health/live`, `/health/ready`; tùy chọn đọc PostgreSQL/PostGIS bằng `psql` để đếm outbox đến hạn, retry ≥8, owner confirmation quá 30 phút và quote hold hết TTL chưa cleanup. Chỉ in số đếm và HTTP status; không in payload, tài khoản, OTP, QR, bank info, connection string.
- API ready kiểm dependency của API; không suy Worker khỏe từ đó. Worker cần process supervision và drill retry/restart riêng.
- Chưa gửi cảnh báo ngoài máy vì người nhận/kênh/retention/RPO/RTO chưa chốt. Script là snapshot local, không là alert daemon.
