# F09.3 — quan sát vận hành local

Ngày 2026-10-10. Trạng thái: **O03 Worker retry/restart PASS trên DB thử; O04 chưa chạy đầy đủ**.

## Phạm vi và contract

- Script read-only kiểm HTTP `/health/live`, `/health/ready`; tùy chọn đọc PostgreSQL/PostGIS bằng `psql` để đếm outbox đến hạn, retry ≥8, owner confirmation quá 30 phút và quote hold hết TTL chưa cleanup. Chỉ in số đếm và HTTP status; không in payload, tài khoản, OTP, QR, bank info, connection string.
- API ready kiểm dependency của API; không suy Worker khỏe từ đó. Worker cần process supervision và drill retry/restart riêng.
- Chưa gửi cảnh báo ngoài máy vì người nhận/kênh/retention/RPO/RTO chưa chốt. Script là snapshot local, không là alert daemon.

## Testcase

| ID | Tình huống | Mong đợi |
|---|---|---|
| O01 | API chạy, DB sẵn sàng | live/ready 200; số đếm DB an toàn. |
| O02 | API/DB dừng | Status báo lỗi, exit nonzero; không ghi PASS. |
| O03 | Outbox retry, owner chờ >30 phút, Worker restart | Đếm đúng; retry/idempotency không gửi trùng; booking đã báo chuyển vẫn giữ. Cần test DB thật. |
| O04 | Log request/payment/OTP | Có traceId cần thiết và không lộ secret/PII; cần review runtime log riêng. |

O03 **PASS** trên bản restore phụ: outbox sai người nhận ghi 1 attempt; sau sửa, Worker restart xử lý đúng 1 notification; restart lần nữa không lặp; booking đã báo chuyển vẫn giữ allocation. Quá SLA tạo đúng 1 outbox đã xử lý và 0 thông báo trùng người nhận. Luồng browser→API→Worker→PostGIS/Mailpit **PASS 8/8** desktop/mobile trên DB tạm, chạy lại **PASS 8/8** sau khi script dùng DataProtection keys riêng. Quét log lượt hai không thấy mẫu email/token/secret/connection string và hết cảnh báo DPAPI key cũ. [Bằng chứng chi tiết](../testing/F09-local-drill-results.md). O04 toàn bộ trace/PII và người nhận cảnh báo vẫn là gate mở. Không thêm thay đổi trạng thái nghiệp vụ sau `CONFIRMED`.
