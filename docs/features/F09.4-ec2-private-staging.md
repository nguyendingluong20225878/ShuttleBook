# F09.4 — gói staging riêng trên Linux/EC2

Trạng thái: IN_PROGRESS (2026-10-17). Người dùng đã tự tạo EC2, kiểm tra role và dừng máy; yêu cầu chuẩn bị mã và kiểm tra local. Không khởi động hay deploy EC2 trong lát cắt này.

## Phạm vi và quyết định

- Đóng gói API, Worker, Migrator, PostgreSQL/PostGIS và ba bản web Vite qua reverse proxy vào Docker Compose. Chỉ bind ba cổng web vào loopback của host để thử qua SSH tunnel; chưa có domain/TLS/public traffic.
- Mỗi web build với API base URL là `http://localhost` ở đúng cổng portal, đi qua Caddy `/api` cùng origin; API và PostgreSQL không publish port ra host. Backend nhận forwarded headers chỉ từ IP reverse proxy cố định trong mạng Compose.
- Khóa ASP.NET Data Protection lưu bền trên volume Linux và được mã hóa bằng certificate PFX nằm ngoài Git. Windows local tiếp tục dùng DPAPI.
- Migrator hoàn tất thành công trước khi API/Worker khởi động. DB và S3 dùng dữ liệu giả, SES sandbox chỉ gửi đến email đã Verified. Không sửa nghiệp vụ, schema hay API response.
- Chưa cấu hình HTTPS public, backup S3 ngoài EC2, SES production access hay đưa link CV; đó là gate tiếp theo.

## Acceptance và contract

1. Build API/Worker/Migrator và ba web bằng image Linux; Compose có healthcheck và restart policy; web trả SPA và reverse proxy `/api` nguyên path.
2. `VITE_API_BASE_URL` của ba build lần lượt là `http://localhost:5173`, `:5174`, `:5175`; browser dùng cùng origin tương ứng khi truy cập bằng tunnel. `BrowserSession`/`AdminSession` origins phải khớp tuyệt đối.
3. API chỉ tin `X-Forwarded-For`/`X-Forwarded-Proto` từ `ReverseProxy:KnownProxy`; giá trị không hợp lệ gây fail startup. `AllowedHosts` được cấu hình rõ theo host staging.
4. `DataProtection:KeysPath` trên Linux yêu cầu `DataProtection:CertificatePath` và PFX hợp lệ; key ring tồn tại sau restart. Thiếu certificate gây fail startup thay vì ghi khóa không mã hóa.
5. Migration là service one-shot trước traffic; chạy lại an toàn. Health `/health/live` và `/health/ready` trả kết quả đúng. S3 dùng EC2 instance role, không có access key tĩnh.
6. Có file mẫu chỉ placeholder, runbook lệnh ngắn theo thứ tự và bảng PASS/NOT RUN. Không lưu secret hoặc dữ liệu thật vào Git/log.

API/error contract: không có endpoint mới hay thay đổi response. Lỗi cấu hình là startup failure; lỗi DB readiness là HTTP 503 theo contract hiện tại. Dữ liệu: không có migration/schema mới; PostGIS và key ring là volume bền riêng. Kiểm thử rủi ro tập trung vào config fail-closed, build, health, login/cookie qua proxy, migration, upload S3 và restart; phép thử AWS live sẽ thực hiện sau khi người dùng bật EC2.
