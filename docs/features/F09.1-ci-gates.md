# F09.1a — CI và gate kiểm thử có thể lặp lại

Ngày: 2026-10-09. Trạng thái: **IN_PROGRESS**. Phạm vi lát cắt độc lập với quyết định trần tiền và quota quote; xem [F09 tổng](F09-production-readiness.md) và [review](../reviews/ShuttleBook-local-predeploy-review.md).

## Mục tiêu và phạm vi

- Workflow Ubuntu cài Node/.NET theo lockfile, typecheck và build ba web, chạy browser fixture trên bản build, build/migrate/API/DB test trên PostgreSQL/PostGIS tạm. Kết quả hosted có URL và trạng thái rõ, không dùng kết quả local thay thế.
- PowerShell local hiện hành vẫn hoạt động. Không sửa nghiệp vụ, schema, API/error contract hoặc dữ liệu development trong lát cắt này.
- `workflow_dispatch` cho phép người dùng chạy lại workflow thủ công trên nhánh có code. Quyền chạy workflow đã được người dùng cấp; commit/push cần quyền riêng theo AGENTS.md.

## Contract kỹ thuật

- Web job trên Ubuntu gọi npm workspace build và Playwright CLI trực tiếp; không gọi `powershell.exe`. `playwright.config.ts` tự khởi động ba Vite preview với port 5173–5175 khi `SHUTTLEBOOK_EXTERNAL_WEB` không đặt. CI cài Chromium và dependencies trước test. Build CI dùng `VITE_MAPTILER_API_KEY=ci-fixture-key` công khai để hiện control MapTiler; browser fixture chặn/stub HTTP MapTiler, không dùng provider thật hay credential.
- Backend job restore/build một lần, chạy migrator hai lần để kiểm lặp an toàn, sau đó API và DB tests **tuần tự** trên PostGIS service. CI dùng signing key/OTP pepper giả chỉ trong job, không dùng tiền hoặc contact thật. Không chạy `dotnet build` trùng lúc `dotnet test` trên cùng output.
- Nếu một lệnh thất bại, job FAIL; 8 ca browser live có chủ đích SKIP vẫn phải chạy riêng trước deploy. Artifact chỉ chứa test-results khi thất bại, không chứa secret/PII.
- Lỗi timeout hoặc DB không kết nối là FAIL/BLOCKED theo evidence, không tự ghi PASS. API và data contract không thay đổi.

## Acceptance và testcase

| ID | Ca kiểm | Mong đợi |
|---|---|---|
| CI-01 | `npm.cmd run typecheck`, `npm.cmd run build` ở PowerShell local | PASS, ba app build; giữ đường local hiện tại. |
| CI-02 | Chạy tương đương Ubuntu: `npm run build --workspaces --if-present`, `npx playwright test --workers=2` trên build mới | PASS local; không gọi PowerShell từ hai lệnh này. |
| CI-03 | Xem workflow YAML và chạy hosted CI trên commit ứng viên | Web/backend job PASS; có run URL/commit SHA; không suy từ YAML. |
| CI-04 | M03 trailing-activity desktop/mobile trong full suite | Không flake; kiểm event thật không bị nhầm polling. Nếu fail phải phân biệt test clock và product bug bằng trace. |
| CI-05 | Full DB suite trên PostGIS tạm, migration fresh/repeat | Có summary cuối, số ca/skip/FAIL và thời lượng; focused PASS không thay full. |

## Điểm còn mở

- Hosted CI chưa chạy trên code mới. Nếu phải commit/push để workflow thấy diff, hỏi quyền Git trước thao tác đó. Không deploy hoặc tạo tài nguyên trả phí.
- Tập browser live/API/Worker/PostGIS/Mailpit và manual UI là gate riêng; không gộp với fixture CI.
