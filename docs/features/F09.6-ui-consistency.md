# F09.6 — nhất quán giao diện ba cổng

Ngày 2026-10-09. Người dùng chọn **giữ nhận diện xanh ShuttleBook**, chuẩn hóa thành phần; không đổi bố cục lớn. Trạng thái: **IN_PROGRESS**.

## Phạm vi lát cắt đầu

- Dùng token chung cho primary/hover, text, muted, border, surface, page, focus, panel radius và kích thước control. Các primitive CSS `sb-panel`, `sb-action`, `sb-field`, `sb-notice` được dùng ở Customer quote, Partner quyết định thanh toán, Admin duyệt hồ sơ. Ba cổng giữ bố cục phù hợp tác vụ; các alias CSS cũ lấy màu từ token chung.
- Customer quote casual hiển thị tiền từ `amountExact`, báo rõ trần tiền/quota; nút lấy quote mới chỉ dùng khi quote cũ hết TTL. Focus ring nhất quán 3px, offset 3px.
- Không đổi nghiệp vụ/route/quyền; không áp dụng redesign diện rộng ở lát cắt này.
