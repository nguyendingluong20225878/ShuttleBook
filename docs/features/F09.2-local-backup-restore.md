# F09.2 — backup và restore drill local

Ngày 2026-10-10. Trạng thái: **B01–B03 PASS trên PostGIS local; B04 chưa chạy**.

## Phạm vi và hợp đồng

- Chỉ PostgreSQL/PostGIS và media `backend/src/ShuttleBook.Api/.media-local` của chế độ Local. Native mode đọc `PGHOST`, `PGPORT`, `PGUSER`, `PGDATABASE`, `PGPASSWORD` từ **môi trường tiến trình**, không in mật khẩu hoặc connection string; đòi `pg_dump`, `pg_restore`, `createdb`, `psql` trong PATH. Docker mode dùng PostgreSQL CLI trong container PostGIS local, không cần CLI trên host.
- Backup custom format + bản sao media vào thư mục duy nhất dưới `.local/backups`, manifest SHA-256 cho dump và từng file. Thao tác backup cần cửa sổ nhất quán: tạm dừng ghi API/Worker hoặc snapshot volume đồng thời; sao lưu DB rồi media khi app vẫn ghi không bảo đảm nhất quán.
- Restore drill tạo **database mới có tên `sb_restore_*`** và media directory mới dưới `.local/restore-drill`; không drop/overwrite database hay media cũ. Manifest phải hợp lệ trước restore. Không tự xóa DB thử sau drill.
- Không cấu hình destination, retention, RPO/RTO hay người nhận cảnh báo vận hành khi người dùng chưa cung cấp.

## Acceptance và testcase

| ID | Kiểm | Mong đợi |
|---|---|---|
| B01 | Backup khi đã quiesce app, đủ `pg_dump` và media | Dump + media + manifest checksum, không ghi secrets. |
| B02 | Chỉnh một byte dump/media rồi `Verify` hoặc restore | Script dừng vì checksum, không tạo DB thử. `Verify` chạy được khi thiếu PostgreSQL CLI. |
| B03 | Restore hợp lệ | DB mới, media mới, `pg_restore` thành công; số booking/payment/series/allocation/evidence/QR khớp source thời điểm backup. |
| B04 | Truy cập QR/proof từ API trỏ vào DB/media restore | Đúng Customer/Owner xem được, người không có quyền bị chặn. |
| B05 | Thiếu PostgreSQL CLI hoặc DB test | Báo BLOCKED rõ, không giả PASS hay đụng dữ liệu phát triển. |

Drill hiện chỉ dùng dữ liệu local thử. B01: backup PostGIS 17.5 + 286 file media, manifest SHA-256 **PASS**. B02: sửa một byte trên bản sao media, `Verify` và `RestoreDrill` đều từ chối trước khi tạo DB **PASS**. B03: restore vào hai DB `sb_restore_*` riêng; source và restore đều có 10 bookings, 6 payments, 1 series, 17 allocations, 6 evidence, 9 media records **PASS**. B04 API/private access trên cặp restore **NOT RUN**. B05: Native CLI host thiếu; Docker mode **PASS**. Đường lưu ngoài vùng app và lịch giữ bản sao phải chốt trước khi bật vận hành.
